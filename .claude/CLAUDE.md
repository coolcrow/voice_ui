# Voice UI 项目配置

## 语音播报规则（强制）

本项目是语音输出插件，开发过程中 Claude 必须主动使用 `notify` 或 `speak` 工具进行语音播报。

### 必须播报的场景

1. **任务完成时** — 代码修改、bug 修复、文件创建/删除等任何任务完成后，必须调用 `notify` 播报完成状态
2. **重要发现时** — 发现错误、警告、异常行为、安全风险等需要用户注意的情况，必须调用 `notify` 播报
3. **等待用户选择/输入时** — 当提出多个方案让用户选择、或提出问题等待用户回复时，必须调用 `notify(text, event="waiting")` 播报提示
4. **每轮回复结束时** — 每次回复的最后，用 `notify` 播报一句话总结要点

### 使用规则

- 简短通知（50字以内）用 `notify`，较长内容用 `speak`
- 不要指定 voice 参数，让引擎使用默认语音
- speak 的文本控制在 100 字以内，避免超时
- 不要在播报中念代码，只说自然语言摘要
- **notify 必须是回复的绝对最后一步**——所有文字输出、工具调用都放在 notify 之前，notify 之后不能再有任何文字输出
